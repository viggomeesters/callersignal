# Support

## Project questions

Use [GitHub Issues](https://github.com/viggomeesters/callersignal/issues) for reproducible repository defects, documentation gaps, and bounded feature proposals. Search existing issues first and include the revision, operating system, Python and `uv` versions, exact command, sanitized output, and expected behavior.

CallerSignal v0.1.0 is a repository-foundation release. CLI, MCP, HTTP, web lookup, country adapters, public reports, and production deployment are open product tasks, not currently supported features.

## Sensitive matters

Use the private route in [`SECURITY.md`](SECURITY.md) for vulnerabilities, privacy exposure, credentials, unsafe logging, or integrity failures. Never post a real phone number, call report, contact identity, request trace, recording, private screenshot, or token in a public support request.

## Design and contribution questions

Read [`docs/onboarding.md`](docs/onboarding.md), [`docs/implementation-plan.md`](docs/implementation-plan.md), and [`CONTRIBUTING.md`](CONTRIBUTING.md). Proposals that affect sources, personal data, moderation, retention, identity claims, or public safety require an explicit design and privacy review before implementation.

There is no service-level support commitment. Maintainers prioritize safety, reproducibility, and clearly scoped `.go` tasks.
