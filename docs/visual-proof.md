# Visual Proof

## Asset intent

The CallerSignal repository hero expresses a left-to-right, international evidence flow: a neutral phone input passes through distinct provenance and interpretation nodes and reaches a structured result over a restrained world-map field. The midnight navy, teal, cyan, cream, and limited coral palette is calm and trustworthy rather than alarmist. The image contains no product claim or real-world identity information.

The hero was generated on 2026-08-26 with OpenAI image generation as a text-free stylized-concept asset. Its prompt requested editorial data cartography, explicit signal and evidence separation, generous safe margins, high contrast, and the exclusion of text, letters, numbers, flags, logos, people, surveillance clichés, warnings, watermarks, and signatures.

The social preview was generated from the inspected hero in a second image-editing pass. That prompt preserved the visual system and recomposed it at a 2:1 ratio with thumbnail contrast and safe-edge requirements; it also prohibited new text, identifiers, logos, and watermarks.

## Visual inspection

Both committed PNG files were inspected at original resolution in Codex on 2026-08-26 after they were copied into the repository.

| Check | Result | Evidence |
| --- | --- | --- |
| Clipping | Pass | Phone, evidence nodes, map contours, routes, and structured output remain fully inside the frame. |
| Overlap | Pass | The primary flow stays visually separated from background routes; no node or output panel obscures another. |
| Contrast | Pass | Cyan and cream foreground strokes remain distinct against midnight navy at full size and thumbnail scale. |
| Readability | Pass | The input → evidence → interpretation → result sequence is legible without depending on text. |
| Private data | Pass | No phone number, person, contact detail, location trace, report, or other personal datum appears. |
| Text content | Pass | The assets contain no words, letters, digits, labels, sample records, or unfinished text. |
| Watermarks | Pass | No logo, signature, vendor mark, or watermark appears. |
| Edge safety | Pass | Core phone and output forms have visible outer padding; the social composition retains safe crop space. |
| Color semantics | Pass | Coral marks uncertainty gaps sparingly and does not create a red danger or fraud verdict. |

No regeneration issue remains. Future asset changes must update dimensions and digests here, rerun `bash scripts/check-assets.sh`, and repeat original-resolution inspection.
